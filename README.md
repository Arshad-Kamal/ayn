# Ayn (عين)

Ayn is an ad-free YouTube client for Android TV and Android phones, built and tested on an NVIDIA
Shield first. There is no sign-in: profiles, subscriptions, history and playlists live on your
device, with optional backup and encrypted sync to storage you choose.

Ayn is an independent project. It is not made by, endorsed by, or affiliated with YouTube or
Google.

## Install

**On an Android TV or Shield:** install [Downloader](https://www.aftvnews.com/downloader/) from
the Play Store, open it and enter the code **9922438**. It opens the
[latest release](https://github.com/Arshad-Kamal/ayn/releases/latest); pick the APK there and
install it.

**On a phone, or by hand:** download `ayn-<version>.apk` from the
[latest release](https://github.com/Arshad-Kamal/ayn/releases/latest) and sideload it. Check it
against the `.sha256` file beside it.

One APK serves both: Ayn picks the TV or the phone interface when it starts. It needs Android 11
(API 30) or newer.

## Privacy

Ayn talks to YouTube (Google) for videos and to three community services for what they add: SponsorBlock
(skip segments), DeArrow (titles and thumbnails) and Return YouTube Dislike (dislike estimates).
Each is sent only the video's ID. Everything else (profiles, history, subscriptions, For you)
stays on the device unless you turn on sync or export a backup.

## Building

You need JDK 21 and the Android SDK. Point Gradle at the SDK with `sdk.dir` in
`local.properties` (or `ANDROID_HOME`), then:

```sh
./gradlew build            # tests, lint, and the release APK
./gradlew assembleRelease  # the APK only: app/build/outputs/apk/release/
```

Dependencies are checked against `gradle/verification-metadata.xml`.

Google Drive sync needs your own OAuth client: put `ayn.google.clientId` and
`ayn.google.clientSecret` in `local.properties`. Without them the Drive option is hidden and
everything else works.

## Modules

- `:app`: the single APK
- `:core`: data, storage, extraction, and streaming behind interfaces
- `:core:extractor`, `:core:sabr`, `:core:potoken`: vendored third-party code (see
  `THIRD-PARTY.md`)
- `:feature`: view models and state
- `:ui:tv`, `:ui:mobile`: the two interfaces (Jetpack Compose)
